# DJ Browser — Downloads

Compiled desktop builds of [DJ Browser](https://dj-browser.vercel.app) for macOS, Windows, and Linux.

This repo holds only release binaries. The application source lives in a
private repository; this repo exists purely so the desktop app can be
downloaded publicly.

## Download

See the [Releases](https://github.com/FistukRraz/dj-browser-releases/releases) page for the latest build.

## What is DJ Browser?

A two-deck DJ mixing app that runs in the browser (as a PWA on mobile) or as
a native desktop app (macOS/Windows/Linux) with real on-device file access,
built with [Tauri](https://v2.tauri.app).
